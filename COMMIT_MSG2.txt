Harden auth, block SSRF, add desktop app and public-API integrations

Security
  SSRF guard in @agentready/shared. Blocks loopback, RFC1918, link-local,
  CGNAT, IPv6 ULA, reserved ranges and non-http schemes. Resolves DNS and
  checks every answer, so a public hostname resolving into a private range is
  rejected. Follows redirects manually so every hop is re-validated. Cloud
  metadata endpoints stay blocked even when private ranges are allowed.

  Auth no longer silently downgrades bad credentials: a caller who presents a
  token that fails verification is rejected, not handed the shared dev user.
  Dev auth requires an explicit AGENTREADY_DEV_AUTH opt-in and resolves to a
  free-plan user so local testing hits the same limits as production.

  A blocked target is reported as 400 blocked_target across /scan and /enrich
  rather than leaking as a 500. The CLI explains the opt-in instead of just
  refusing.

  serverSlug strips path separators and shell metacharacters, refuses a
  leading dash a child process would read as a flag, and never returns empty.

Features
  Desktop app: a standalone application window that boots the API and web
  server in-port. Uses the system browser in --app mode rather than bundling
  Electron, so it installs instantly.

  enrich: reports what an agent can learn about a domain before fetching it,
  using four free key-less public APIs - crt.sh for certificate-transparency
  subdomain discovery, Cloudflare DNS-over-HTTPS for records, the Wayback
  Machine for archive history, and RDAP for domain age. All degrade to
  "unavailable"; none can fail a scan.

  /verify resolves a site by URL instead of reading the first site of a
  hardcoded user, which could report another tenant's score.

Tests
  305 across 8 files, including 41 security tests and an end-to-end
  acceptance script that boots the desktop app, runs all seven CLI commands
  and asserts every guard holds.
